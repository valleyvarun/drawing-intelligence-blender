Drawing Intelligence

Sketch in 3D with a pen or mouse. Powered by Blender.

Download for Windows

Windows 10 or 11, x64 · Blender runtime included by setup

The installer runs on Windows only. Open this page on a Windows PC to install Drawing Intelligence for Blender.

Install in four steps

  1. Run the installer. Download and open Drawing-Intelligence-Blender-Setup.exe. The installer is not code-signed yet; Windows may show a publisher warning. Confirm that the download came from this repository before continuing.
  2. Review the Blender information. Setup uses the official Blender 5.2.2 LTS runtime and links to its license and source code.
  3. Choose a folder and install. Setup downloads Blender and the drawing app, checks the Blender archive, and creates shortcuts. Keep your internet connection active until it finishes.
  4. Start drawing. Open Drawing Intelligence (Blender) from your desktop or Start menu. Choose Paint, Pipe, or Grease Pencil and draw in the viewport.

What the installer does

  • Downloads Blender 5.2.2 LTS for Windows x64 and verifies its SHA-256 checksum.
  • Downloads the drawing app from this GitHub repository.
  • Installs the runtime in the app’s engine folder, with an isolated settings profile.
  • Adds a Start menu entry, an optional desktop shortcut, and an uninstaller in Windows Settings.

The default folder is %LOCALAPPDATA%\Programs\Drawing-Intelligence-Blender. Spaces in folder names are supported. You can choose another writable folder.

Requirements

  • Windows 10 or 11, 64-bit x64
  • A computer that meets Blender’s system requirements, with current graphics drivers
  • Allow about 5 GB of free disk space during installation
  • An internet connection during installation

You do not need to install Blender, Git, or build tools yourself. The default installation does not require administrator rights.

Update or uninstall

To update, close the app and run setup again. It downloads the latest published app, replaces its application files, and preserves your projects and runtime preferences.

To uninstall, open Settings > Apps > Installed apps, find Drawing Intelligence (Blender), and select Uninstall. The app and its private Blender engine are removed. Saved projects and runtime preferences stay in place.

Keep your drawings in a project folder of your choice. Native .blend files preserve the complete drawing data.
